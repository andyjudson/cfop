# Implementation Plan — Feature 023: wca-data-refresh

**Branch**: `023-wca-data-refresh` | **Date**: 2026-05-09 | **Spec**: [spec.md](spec.md)

## Summary

Port the PySpark notebook (`pyspark.sandbox/wca_parser.ipynb`) transforms to a uv-managed Python CLI that downloads the WCA public export and regenerates three NDJSON files consumed by cfop-app. Exposed as a `/refresh-wca` Claude Code skill and a monthly GitHub Actions schedule.

---

## Technical Context

**Language/Version**: Python 3.11+  
**Package manager**: uv (replaces Poetry; `pyproject.toml` uses PEP 621 `[project.scripts]`)  
**Primary dependencies**: requests, pandas, typer, rich  
**Storage**: `.cache/` (gitignored TSV cache); `cfop-app/public/data/` (output JSON)  
**Testing**: pytest  
**Target platform**: macOS (local dev) + Ubuntu GitHub Actions runner  
**Project type**: CLI tool  
**Performance goals**: Full run < 2 min; transforms < 30s (data is small once filtered to 3x3x3)  
**Constraints**: No Spark dependency; atomic writes; offline mode (`--no-download`)

## Key Implementation Notes

### Staleness check

```python
import re, requests
resp = requests.head(WCA_EXPORT_URL, allow_redirects=False)
location = resp.headers.get("Location", "")
# e.g. "...WCA_export_v2_129_20260509T000027Z.tsv.zip"
match = re.search(r'_(\d{8}T\d{6}Z)\.tsv\.zip', location)
remote_ts = match.group(1) if match else None
# Compare to metadata.json["export_date"] in cache
```

### `--year` parameter scope

**Critical:** `--year` gates **championship competitions only** — WR competitions are always included regardless. The existing `wca-beat-the-champion.json` has data from 2015; a fresh run with `--year 2026` would drop championships from 2015–2025.

**Default should be 2015** (matching notebook and existing data scope). The spec clarification recorded "current year" based on an assumption of incremental updates — but the script always rebuilds from source (no append mode). See research.md Decision 4.

### Atomic writes

```python
import tempfile, os
tmp = output_path.with_suffix(".tmp")
df.to_json(tmp, orient="records", lines=True)
tmp.rename(output_path)  # atomic on POSIX
```

### GitHub Action

```yaml
name: Refresh WCA Data

on:
  schedule:
    - cron: '0 6 1 * *'   # monthly, 1st of month at 06:00 UTC
  workflow_dispatch:

permissions:
  contents: write

jobs:
  refresh:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: astral-sh/setup-uv@v2
      - run: uv sync
        working-directory: scripts/wca-refresh
      - run: uv run wca-refresh
        working-directory: scripts/wca-refresh
      - run: |
          git config user.name "github-actions[bot]"
          git config user.email "github-actions[bot]@users.noreply.github.com"
          git add cfop-app/public/data/
          if ! git diff --quiet --cached; then
            git commit -m "chore(data): refresh WCA data (export $(date +%Y-%m-%d))"
            git push
          fi
```

Cache is not persisted between CI runs — each run downloads fresh (~300MB, ~30–60s).
