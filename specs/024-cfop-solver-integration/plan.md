## Summary

Replace the Kociemba single-alg Solve button on CubifyPage with a stage-by-stage CFOP solve experience. The solver (`CfopSolver` from `@andyjudson/cubify` v1.3.10+) returns 7 annotated stages; `CubifyPage` drives playback through them one at a time via the existing `<CubePlayer>` prop interface, updating stickering, accumulated setup, and the info panel per stage. All solver and mask logic lives in the cubify library — cfop-app only wires state and events.

## Architecture Decisions

### Prop-driven stage playback (no imperative ref calls)

`<CubePlayer>` reacts to `alg`, `setup`, and `stickering` prop changes by calling `player.loadAlg()` internally. Advancing `cfopStageIndex` triggers a React re-render that updates all three props simultaneously — the player loads the new stage without any imperative ref call.

### Ref mirrors for stable callbacks

`handleComplete` and `handlePlayToggle` are `useCallback` instances that read CFOP state. Three ref mirrors avoid stale closures without forcing callback recreation on every state change:

- `cfopStagesRef` — mirrors `cfopStages` state
- `cfopStageIdxRef` — mirrors `cfopStageIndex` state
- `cfopSetupRef` — mirrors `cfopSetup` state

Follows the existing `modeRef` pattern in the file.

### Accumulated setup = scramble + z2 + prior stage algs

`CfopSolution.setupAlg = 'z2'` signals the solver's internal orientation. The initial accumulated setup is `[scrambleAlg, solution.setupAlg].join(' ')`. After each stage the stage's alg is appended. `<CubePlayer setup={cfopSetup}>` positions the cube correctly at the start of each stage.

### Empty stage skipping at completion time

In `handleComplete`, after computing `nextIdx`, scan forward over stages with empty algs. Handles consecutive empties without a `useEffect` loop.

### Kociemba solver removed

`CubeSolver` (Kociemba) and `solverRef` are removed entirely. `CfopSolver` replaces them with the same `useEffect` init + `dispose()` cleanup pattern.

## State Design

### New state

| Name | Type | Purpose |
|------|------|---------|
| `cfopStages` | `SolveStage[] \| null` | Solver result; null until first solve |
| `cfopStageIndex` | `number` | Index into cfopStages for current stage |
| `cfopSetup` | `string` | Accumulated setup string for `<CubePlayer setup>` |

### New refs

| Name | Mirrors | Why ref |
|------|---------|---------|
| `cfopSolverRef` | `CfopSolver` instance | Solver lifetime, not reactive |
| `cfopStagesRef` | `cfopStages` | Read in `handleComplete` without dep |
| `cfopStageIdxRef` | `cfopStageIndex` | Read in `handleComplete` without dep |
| `cfopSetupRef` | `cfopSetup` | Read in `handleComplete` without dep |

### Removed

| Removed | Reason |
|---------|--------|
| `solveAlg: string \| null` | Replaced by `cfopStages` + `cfopStageIndex` |
| `solverRef: CubeSolver` | Replaced by `cfopSolverRef: CfopSolver` |

### Derived values (unchanged shape, new solve-mode branches)

```typescript
const activeAlg   = mode === 'case' ? activeCase.alg
                  : mode === 'scramble' ? (scrambleAlg ?? '')
                  : (cfopStages?.[cfopStageIndex]?.alg ?? '');

const activeSetup = mode === 'case' ? CubeState.setupFromAlg(activeCase.alg, activeCase.rotation)
                  : mode === 'scramble' ? ''
                  : cfopSetup;

const activeMask  = mode === 'case' ? mask
                  : mode === 'solve' ? (cfopStages?.[cfopStageIndex]?.mask ?? 'full')
                  : 'full';
```

### Status message (derived, no new state)

```typescript
const cfopStage = cfopStages?.[cfopStageIndex];

const statusMessage =
  isScrambling ? 'Scrambling… using WCA random-state method' :
  isSolving    ? 'Solving… CFOP method' :
  (mode === 'solve' && cfopStages && !cfopStage)
    ? `Solved! ${cfopStages.reduce((n, s) => n + s.moves, 0)} moves` :
  (mode === 'solve' && cfopStage)
    ? buildStageStatus(cfopStage, playing) :
  null;
```

`buildStageStatus` (inline helper): humanises label (`f2l-fr` → `f2l fr`), appends case name + WCA ID where present, adds alg, and appends `— press play to simulate stage` when `!playing`.

## Key Logic

### `handleSolve` (full replacement)

```
1. Guard: scrambleDone && scrambleAlg && !isSolving && cfopSolverRef.current
2. setIsSolving(true)
3. state = await CubeState.fromAlg(scrambleAlg)
4. solution = await cfopSolverRef.current.solve(state)
5. initialSetup = [scrambleAlg, solution.setupAlg].join(' ')
6. Update refs immediately: cfopStagesRef.current = solution.stages,
   cfopStageIdxRef.current = 0, cfopSetupRef.current = initialSetup
7. setCfopStages / setCfopStageIndex(0) / setCfopSetup(initialSetup)
8. setMode('solve'), setScrambleDone(false), setPlaying(false)
   — no autoPlay(): player loads stage 0 automatically via prop change, paused
9. setIsSolving(false) in finally
10. On error: log, leave mode as 'scramble'
```

### `handleComplete` (additions for solve mode)

```
existing: setPlaying(false); if scramble → setScrambleDone(true)

add: else if modeRef.current === 'solve':
  stages    = cfopStagesRef.current
  idx       = cfopStageIdxRef.current
  setup     = cfopSetupRef.current
  completed = stages[idx]
  newSetup  = completed?.alg ? [setup, completed.alg].join(' ') : setup
  nextIdx   = idx + 1
  while nextIdx < stages.length && !stages[nextIdx].alg: nextIdx++
  cfopSetupRef.current    = newSetup
  cfopStageIdxRef.current = nextIdx
  setCfopSetup(newSetup)
  setCfopStageIndex(nextIdx)
  // nextIdx >= stages.length → activeAlg becomes '' → player loads empty alg → status shows "Solved!"
```

### `handlePlayToggle` (guard for completed solve)

```
add early return:
  if modeRef.current === 'solve'
     && !cfopStagesRef.current[cfopStageIdxRef.current]?.alg: return
```
